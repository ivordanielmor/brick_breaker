# Brick Breaker Game

## 🎮 Description (English)
This is a classic **Brick Breaker** game built with `pygame`. You control a paddle to bounce a ball that breaks colored bricks. Score points by breaking different types of bricks. Golden bricks appear occasionally for bonus points! Includes background music, sound effects, and multiple difficulty levels.

### 🔹 Features
- 3 selectable difficulty levels (Easy, Medium, Hard)
- Animated ball trail and paddle squash effect
- Special golden bricks worth 5 points
- Background music and sound effects (toggle with `M`)
- Restart with `R`, return to lobby with `N` after win, and quit with `Q`

## 🕹 Controls
- Arrow keys: Move paddle
- M: Mute/unmute background music
- R: Restart current level
- N: Go back to level select (after win)
- Q: Quit game

## 🧱 Játék leírása (Magyarul)
Ez egy klasszikus **Brick Breaker** játék `pygame` használatával. Az ütőddel irányítod a labdát, amellyel színes téglákat kell eltüntetni. Különböző pontokat kapsz a téglákért. Időnként arany téglák is megjelennek, amelyek extra pontot érnek! A játék háttérzenével, hangeffektekkel és több nehézségi szinttel is rendelkezik.

### 🔹 Főbb jellemzők
- 3 választható nehézségi szint (Easy, Medium, Hard)
- Animált labdanyom és ütő deformálódás
- Speciális arany téglák (5 pontot érnek)
- Háttérzene és hangeffektek (M gombbal ki-/bekapcsolható)
- R: újraindítás, N: vissza a lobbyhoz, Q: kilépés

## 🕹 Irányítás
- Bal/Jobb nyíl: ütő mozgatása
- M: Zene némítása/folytatása
- R: újrakezdés
- N: visszatérés a szintválasztóba (győzelem után)
- Q: kilépés
